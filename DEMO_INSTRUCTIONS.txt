🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Issue: Server won't start
Fix: npm install
     npm run dev

Issue: Port already in use
Fix: Server will auto-select another port (5174, 5175, etc.)

Issue: Login not working
Fix: Ensure you're using: CUST001 / password123

Issue: Page not loading
Fix: Clear browser cache or use incognito mode

Issue: Transactions not showing
Fix: Refresh the page or logout and login again

📝 COMMON QUESTIONS & ANSWERS
═══════════════════════════════════════════════════════════════

Q: Does it work without a backend?
A: Yes, it has a complete mock API system for demonstration.

Q: Can it connect to a real backend?
A: Yes, just update the .env file with your API URL.

Q: Is it responsive?
A: Yes, fully responsive across all devices.

Q: What security features are included?
A: Token-based auth, protected routes, input validation, 
   transaction confirmations.

Q: Can users export their transactions?
A: Yes, transaction history can be exported to CSV.

Q: How is state managed?
A: Using React Context API for global state management.

Q: What chart library is used?
A: Recharts for the balance trend visualization.

Q: Is the code well-organized?
A: Yes, follows component-based architecture with clear separation.
